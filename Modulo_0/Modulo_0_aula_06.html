4. O que é um Sistema Operacional?

O Sistema Operacional, ou SO, é o software principal que organiza recursos do computador e cria um ambiente para que outros programas funcionem.

⌨️🖱️

Recebe comandos

Ajuda a interpretar ações do teclado, mouse, tela sensível ao toque e outros dispositivos.

📁

Organiza arquivos

Permite criar, abrir, copiar, mover, renomear e apagar arquivos e pastas.

🧩

Executa programas

Navegadores, editores, jogos e outros aplicativos usam os serviços do sistema operacional.

⚙️

Controla hardware

Gerencia recursos como armazenamento, memória, rede, impressoras e outros dispositivos.

Uma comparação útil

Podemos imaginar o sistema operacional como a casa onde os programas vivem ou a “roupa” que o computador veste para que possamos usá-lo. É uma comparação didática: tecnicamente, ele é um conjunto de softwares que gerencia o sistema.

5. Windows e Linux

🪟

Windows

É uma família de sistemas operacionais da Microsoft e é muito comum em computadores pessoais, escolas e empresas.

Tem elementos como Área de Trabalho, Menu Iniciar, Barra de Tarefas e Explorador de Arquivos.

🐧

Linux

Linux é o núcleo usado por várias distribuições. Uma delas é o Ubuntu, um sistema operacional de código aberto para PCs e notebooks.

Existem diferentes distribuições Linux, com interfaces e objetivos distintos. Muitas podem ser usadas gratuitamente.

Quem é melhor?

Essa não é a pergunta principal desta aula. Sistemas diferentes servem a necessidades diferentes. O importante agora é perceber que um computador pode funcionar com sistemas operacionais diferentes.

6. Ligando e desligando do jeito certo

Ligar

Pressione o botão de energia uma vez e espere o sistema iniciar.

Entrar

Espere a Área de Trabalho aparecer e o sistema terminar de carregar.

Usar

Abra programas e arquivos normalmente.

Salvar

Antes de sair, salve seus trabalhos e feche o que estiver usando.

Desligar

No Windows: Iniciar → Ligar/Desligar → Desligar.

Esperar

Espere o computador terminar o desligamento antes de desligar filtros de linha ou retirar energia.

Por que não arrancar da tomada?

O sistema pode estar salvando arquivos, finalizando programas ou realizando outras operações. O desligamento correto permite que ele encerre essas tarefas de forma organizada.

7. Área de Trabalho: nossa primeira organização

Agora vem a parte prática. Vamos criar uma pasta para entender como o sistema organiza informações.

Vá para a Área de Trabalho

Minimize as janelas abertas até enxergar o fundo da Área de Trabalho.

Clique com botão direito

Escolha uma área vazia, sem clicar em um ícone existente.

Escolha “Novo”

No menu que aparecer, procure a opção Novo.

Escolha “Pasta”

O Windows criará uma nova pasta aguardando um nome.

Dê um nome

Digite Curso SEMAS e pressione Enter.

Abra

Dê dois cliques na pasta e observe que ela está vazia: acabamos de criar um espaço para organizar arquivos.

Atalho de teclado para explorar depois

Windows + E abre o Explorador de Arquivos, onde você pode navegar por pastas e unidades.
