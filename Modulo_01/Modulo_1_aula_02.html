Testando a Internet e Comandos do PowerShell

Na aula anterior usamos o CMD. Agora vamos conhecer o PowerShell, descobrir o endereço IP do computador e fazer testes simples de rede para observar conectividade e tempo de resposta.

Desafio da aula: identificar o IPv4 do computador e interpretar um teste de rede sem confundir latência com velocidade de download.

3. CMD e PowerShell: qual é a diferença?

CMD

É o interpretador de comandos tradicional do Windows. Continua útil para muitos comandos clássicos.

C:\Users\Aluno> ipconfig

PowerShell

É um shell e linguagem de automação com recursos mais avançados. Também consegue executar muitos comandos tradicionais do Windows.

PS C:\Users\Aluno> ipconfig

O CMD não “morreu”

Os dois existem no Windows. A ideia desta aula é perceber que PowerShell oferece mais possibilidades para automação e administração, sem deixar de aceitar muitos comandos antigos.

5. Descobrindo o IP com ipconfig

No PowerShell, digite:

PS C:\Users\Aluno> ipconfig

IPv4

Procure algo como Endereço IPv4. Exemplo didático: 192.168.1.23.

Gateway padrão

É normalmente o endereço usado para alcançar outras redes, muitas vezes o roteador local.

Adaptador

Pode aparecer Ethernet, Wi‑Fi e outros adaptadores. Nem todos estarão conectados.

Esse IPv4 é o “IP da internet”?

Nem sempre. Em redes domésticas e escolares, o endereço mostrado costuma ser um IP privado/local. O endereço público usado na internet é outro conceito.

6. Testando a conectividade com PowerShell

Uma forma moderna de testar se outro computador ou serviço pode ser alcançado é:

PS C:\Users\Aluno> Test-Connection google.com -Count 4

Esse comando envia solicitações de eco, parecidas com o ping, e mostra as respostas.

Outro teste útil

O PowerShell também possui Test-NetConnection, usado para diagnóstico de conectividade. Para esta aula, vamos apenas conhecer o nome e manter o teste prático simples.

7. “Internet rápida ou lenta?” — vamos falar direito

Para tornar a aula divertida, vamos observar o tempo de resposta. Isso não é a mesma coisa que velocidade de download.

🟢

Resposta baixa

Menor tempo de resposta costuma significar sensação mais ágil em jogos, chamadas e navegação.

🟡

Resposta média

Pode funcionar normalmente, mas algumas atividades em tempo real podem sentir atraso.

🔴

Resposta alta ou perdas

Pode indicar atraso, instabilidade ou problema no caminho até o destino.

Não transforme números em regra absoluta

O resultado depende do destino, distância, Wi‑Fi, provedor, horário e rota. Nesta aula o “semáforo” serve apenas para comparar resultados entre testes, não para dizer que uma conexão é boa ou ruim por um número isolado.

8. Atividade prática: Semáforo da conexão

🏫 No laboratório

  1. Abra o PowerShell.
  2. Execute ipconfig e encontre o IPv4.
  3. Execute Test-Connection google.com -Count 4.
  4. Observe os tempos de resposta.
  5. Compare com um colega: os resultados são exatamente iguais?
  6. Classifique de forma lúdica como “mais rápido de responder”, “intermediário” ou “mais demorado”, sem tratar isso como teste de velocidade.

📱 Pelo celular

Não instale terminal nem aplicativo extra.

  1. Leia os exemplos de ipconfig e Test-Connection.
  2. Explique o que é IPv4.
  3. Explique o que significa um tempo em milissegundos.
  4. Faça a prática quando retornar à SEMAS.
