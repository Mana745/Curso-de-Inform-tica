Deixando o Site Colorido e Animado

O HTML organiza o conteúdo. Agora vamos conhecer o CSS, a linguagem usada para controlar a aparência da página: cores, alinhamento, espaços, bordas, cantos e efeitos visuais.

Desafio da aula: transformar a página simples das aulas anteriores em uma página mais agradável, legível e organizada — sem exagerar nos efeitos.

3. O que é CSS?

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata. É a linguagem usada para descrever a apresentação de documentos como HTML.

HTML

“Isto é um título.”
“Isto é um parágrafo.”

CSS

“O título será azul.”
“O fundo será claro.”
“A caixa terá borda e espaço interno.”

4. Onde vamos colocar o CSS hoje?

Para não criar muitos arquivos de uma vez, nesta aula colocaremos o CSS dentro da tag <style>, no <head>.

<head> <meta charset="utf-8"> <title>Minha Página</title> <style> body { background-color: lightblue; } </style> </head>

Mais adiante existem outras formas

Projetos maiores normalmente podem usar arquivos CSS separados. Hoje o objetivo é enxergar claramente a relação entre uma regra CSS e o resultado.

5. Como ler uma regra CSS

body { background-color: lightblue; }
bodyÉ o seletor: diz qual elemento queremos estilizar.
background-colorÉ a propriedade: diz o que queremos alterar.
lightblueÉ o valor: diz qual configuração será usada.

6. Mudando a cor do fundo

body { background-color: lightblue; }

A propriedade background-color define a cor de fundo do elemento.

Bonito também precisa ser legível

Uma cor de fundo não deve dificultar a leitura. Fundo e texto precisam ter contraste suficiente.

7. Mudando a cor das letras

body { background-color: lightblue; color: darkblue; }

A propriedade color define a cor do texto.

8. Estilizando apenas o título

h1 { color: darkgreen; }

Agora a regra afeta elementos <h1>, não toda a página.

9. Centralizando o texto

h1 { text-align: center; }

A propriedade text-align controla o alinhamento horizontal do conteúdo textual dentro do elemento.

Nem tudo precisa ficar centralizado

Títulos curtos podem funcionar bem no centro. Parágrafos longos costumam ser mais confortáveis alinhados à esquerda. Design também é escolher onde não aplicar um efeito.

10. Criando uma caixa de conteúdo

Vamos usar um elemento <div> como uma caixa que agrupa conteúdo.

<div class="caixa"> <h2>Sobre nossa região</h2> <p>Aqui vai um texto importante.</p> </div>

Depois damos estilo a essa caixa:

.caixa { background-color: white; border: 2px solid steelblue; padding: 20px; border-radius: 12px; }

11. O que cada propriedade da caixa faz?

background-color

Cor do fundo da caixa.

border

Cria uma borda em volta.

padding

Cria espaço entre o conteúdo e a borda.

border-radius

Arredonda os cantos.

12. O começo do “modelo de caixa”

Elementos de uma página podem ser pensados como caixas. Dentro está o conteúdo; ao redor podem existir padding, border e espaço externo.

Hoje não precisamos decorar todo o modelo de caixa. Basta perceber que padding cria espaço dentro da borda.

13. Adicionando uma sombra leve

.caixa { box-shadow: 0 6px 16px rgba(0, 0, 0, 0.15); }

box-shadow permite desenhar uma sombra ao redor da caixa.

Sombra é destaque, não obrigação

Uma sombra discreta pode ajudar a separar visualmente elementos. Muitas sombras fortes deixam a página confusa.

14. Um efeito visual simples ao passar o mouse

.caixa { transition: transform 0.2s; } .caixa:hover { transform: translateY(-3px); }

A ideia é simples: quando o ponteiro passa sobre a caixa, ela se move alguns pixels e a mudança acontece suavemente.

“Animado” não significa “ficar mexendo o tempo todo”

Efeitos devem ajudar a perceber interação ou destaque. Piscadas, movimentos contínuos e exageros podem atrapalhar leitura e concentração.

16. Nosso código completo de exemplo

<!doctype html> <html lang="pt-BR"> <head> <meta charset="utf-8"> <title>Minha Região</title> <style> body { background-color: lightblue; color: #173047; font-family: Arial, sans-serif; } h1 { color: darkblue; text-align: center; } .caixa { background-color: white; border: 2px solid steelblue; padding: 20px; border-radius: 12px; box-shadow: 0 6px 16px rgba(0, 0, 0, 0.15); transition: transform 0.2s; } .caixa:hover { transform: translateY(-3px); } </style> </head> <body> <h1>Conheça Minha Região</h1> <div class="caixa"> <h2>Nossa comunidade</h2> <p>Aqui vai um texto escrito pelo aluno.</p> </div> </body> </html>

17. O que é class="caixa"?

A palavra class permite dar um nome de classe a um elemento para que possamos selecioná-lo no CSS.

<div class="caixa"> ... </div>

No CSS, uma classe é selecionada com um ponto:

.caixa { background-color: white; }

Ao final, sua página deverá ter:

1 título centralizado

Use text-align: center.

1 caixa

Use div class="caixa".

Borda + espaço

Use border e padding.

Sombra ou movimento suave no hover.

21. Erros comuns

❌ Esquecer ;

color: blue background-color: white;

✅ Separar declarações

color: blue; background-color: white;

❌ Esquecer a chave

h1 { color: blue;

✅ Fechar o bloco

h1 { color: blue; }

22. Beleza não é só colocar mais coisas

Design também é clareza

Uma página com 10 cores, textos piscando e muitas sombras pode ficar pior do que uma página simples. O objetivo é facilitar leitura, organização e compreensão.
