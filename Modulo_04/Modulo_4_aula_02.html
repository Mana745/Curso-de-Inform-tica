O Que é o Código HTML?

Quando você abre uma página da internet, o navegador recebe informações estruturadas. Uma das tecnologias usadas para construir essa estrutura é o HTML.

Desafio da aula: reconhecer as partes básicas de um documento HTML e entender como um texto escrito em código vira uma página no navegador.

3. O que significa HTML?

HTML significa HyperText Markup Language, em português, Linguagem de Marcação de Hipertexto.

Ela define a estrutura e o significado do conteúdo de uma página da Web: títulos, parágrafos, links, imagens, listas e muitas outras partes.

HTML não é “o site inteiro”

HTML cuida principalmente da estrutura e do conteúdo. CSS costuma cuidar da aparência, e JavaScript pode adicionar comportamento e interatividade.

4. A comparação do esqueleto

🦴 HTML

Estrutura e organização do conteúdo.

🎨 CSS

Aparência: cores, tamanhos, espaços e layout.

⚙️ JavaScript

Comportamentos e interações.

É uma analogia

Dizer que HTML é o “esqueleto” ajuda a visualizar sua função, mas tecnicamente HTML é uma linguagem de marcação que estrutura e dá significado ao conteúdo.

5. O que são tags?

Tags são marcações escritas entre os sinais < e >. Elas ajudam a formar elementos HTML.

<h1>Minha primeira página</h1> <p>Estou aprendendo HTML.</p>

No exemplo acima:

<h1>

Marca o início de um título principal.

</h1>

Marca o fechamento desse título.

<p>

Marca o início de um parágrafo.

</p>

Fecha o parágrafo.

6. Tag e elemento não são exatamente a mesma coisa

1
Tag de abertura: <p>
2
Conteúdo: Minha comunidade
3
Tag de fechamento: </p>
<p>Minha comunidade</p>

O conjunto completo forma um elemento HTML. Muitos elementos usam abertura + conteúdo + fechamento.

7. Nem toda tag funciona exatamente do mesmo jeito

Alguns elementos HTML não envolvem texto e não usam uma tag de fechamento da mesma forma, como imagens. Vamos aprender essas diferenças nas próximas aulas.

8. A estrutura básica de uma página

<!doctype html> <html lang="pt-BR"> <head> <meta charset="utf-8"> <title>Minha página</title> </head> <body> <h1>Olá!</h1> <p>Esta é minha primeira página.</p> </body> </html>

9. O que cada parte faz?

<!doctype html>

Indica ao navegador que estamos usando um documento HTML moderno.

<html>

É o elemento raiz do documento HTML.

<head>

Guarda informações sobre a página que normalmente não aparecem como conteúdo principal.

<title>

Define o título do documento mostrado, por exemplo, na aba do navegador.

<body>

Contém o conteúdo principal que aparece na página.

<h1> e <p>

Representam um título principal e um parágrafo.

11. O HTML “roda”?

No dia a dia, alguém pode dizer que “o HTML roda no navegador”. Para aprender tecnicamente melhor, vamos usar outra frase:

✅ O navegador interpreta o HTML e renderiza a página

O arquivo contém marcações. O navegador lê essa estrutura e apresenta o conteúdo visualmente.

HTML não é um programa executável como muitos programas tradicionais

Ele é uma linguagem de marcação. A página pode também usar CSS e JavaScript, que cumprem outras funções.

12. Um arquivo HTML pode existir sem internet

Você pode criar um arquivo como:

minha_pagina.html

e abri-lo diretamente em um navegador do computador, mesmo sem publicar em um site.

Isso será importante no laboratório

Nas próximas aulas, podemos escrever os arquivos no PC da SEMAS e abrir localmente no navegador para ver o resultado imediatamente.

13. E no celular?

HTML é um padrão da Web amplamente suportado pelos navegadores modernos. Um documento HTML publicado na Web pode ser acessado tanto por computador quanto por celular.

💻 PC

Chrome, Edge, Firefox e outros navegadores conseguem interpretar páginas HTML.

📱 Celular

Navegadores móveis também interpretam HTML.

Mesma página não significa aparência idêntica

O tamanho da tela, o navegador e o CSS podem mudar a forma como a página aparece. Mais adiante aprenderemos a fazer páginas que se adaptam melhor.

14. HTML não precisa de um programa especial para existir

Um arquivo HTML é essencialmente um arquivo de texto com marcações. Podemos escrevê-lo em um editor de texto ou em um editor de código.

📝 Editor de texto

Pode criar o arquivo, desde que ele seja salvo corretamente como .html.

💻 Editor de código

Ferramentas como VS Code tornam a escrita e organização do código mais confortável.

🌐 Navegador

Abre o arquivo e mostra o resultado.

17. Cuidado com três confusões comuns

HTML ≠ Internet

HTML é uma linguagem usada em documentos Web. Internet é a rede que conecta sistemas.

HTML ≠ navegador

O navegador é o programa que interpreta e exibe a página.

HTML ≠ “site bonito”

HTML sozinho já estrutura conteúdo, mas aparência sofisticada geralmente envolve CSS.
