3. O que é o Visual Studio Code?

O VS Code é um editor de código. Ele ajuda a criar, visualizar e organizar arquivos de programação e desenvolvimento Web.

“Programadores de verdade usam VS Code” — melhor dizendo

Muitos profissionais usam VS Code, mas existem diversos outros editores e ambientes de desenvolvimento. O que faz alguém programar não é a marca do editor — é saber criar, entender, testar e corrigir código.

4. Editor de texto × editor de código

📝 Editor de texto simples

Permite escrever texto puro e pode até criar HTML se o arquivo for salvo corretamente.

💻 Editor de código

Além de escrever texto, oferece recursos para organização de arquivos, realce de sintaxe, busca e outras ferramentas de desenvolvimento.

7. Activity Bar — a barra de atividades

Normalmente fica na lateral e dá acesso às principais áreas.

📄 Explorer

Arquivos e pastas do projeto.

🔎 Search

Busca texto nos arquivos.

⑂ Source Control

Ferramentas de controle de versão — conheceremos só mais adiante, se necessário.

▶ Run

Área de execução e depuração para linguagens que usam esses recursos.

🧩 Extensions

Permite adicionar recursos ao editor.

8. Explorer — nosso armário de arquivos

O Explorer mostra os arquivos e pastas do projeto. É ali que podemos criar, renomear, excluir e organizar itens.

PROJETO_SEMAS/ ├── index.html ├── imagens/ └── outros_arquivos...

Explorer do VS Code ≠ Explorador de Arquivos do Windows

Os dois trabalham com arquivos e pastas, mas são interfaces diferentes. O Explorer do VS Code mostra principalmente o conteúdo da pasta de projeto aberta no editor.

9. Editor — onde escrevemos o código

A região maior no centro é o Editor. Quando abrimos um arquivo, ele aparece ali para leitura e edição.

<h1>Minha primeira página</h1>

É nessa área que começaremos a escrever HTML nas próximas aulas.

10. Abas

Quando vários arquivos estão abertos, eles podem aparecer em abas.

[ index.html ] [ contato.html ] [ sobre.html ]

Isso permite trocar rapidamente entre arquivos do mesmo projeto.

11. Barra de status

Na parte inferior, a barra de status pode mostrar informações úteis, como:

HTML

Linguagem detectada para o arquivo.

UTF-8

Codificação do texto.

Ln / Col

Linha e coluna onde o cursor está.

12. Por que o código aparece colorido?

O VS Code usa realce de sintaxe para colorir partes do código de acordo com a linguagem.

<h1>Meu título</h1> <p>Meu texto</p>

As cores ajudam a ler

Elas facilitam distinguir tags, atributos, textos, palavras especiais e outras partes do código.

13. Cor não significa “código correto”

⚠️ O realce ajuda, mas não garante

Um trecho pode aparecer colorido e ainda conter erro de lógica, estrutura ou digitação. A cor é uma ajuda visual, não uma prova de que tudo está certo.

14. O VS Code já entende HTML?

Sim. O VS Code possui suporte integrado para HTML, além de várias outras linguagens comuns.

Quando salvamos um arquivo com extensão .html, o editor consegue reconhecer a linguagem e oferecer recursos adequados.

15. O que é uma pasta de projeto?

Para nossas aulas, será uma pasta que reúne os arquivos de uma página ou atividade.

Curso_SEMAS_HTML/ ├── Aula_03/ ├── Aula_04/ ├── Aula_05/ └── Projeto_Final/

Organização importa porque, conforme um projeto cresce, podem existir páginas, imagens e outros arquivos relacionados.

17. O que é um workspace?

Quando abrimos uma pasta no VS Code, ela pode funcionar como nosso espaço de trabalho ou workspace.

Para esta turma, mantenha simples

Vamos trabalhar normalmente com uma pasta principal aberta por vez. O VS Code possui workspaces mais avançados com várias pastas, mas ainda não precisamos disso.

18. Se aparecer “Do you trust the authors of the files in this folder?”

Workspace Trust

O VS Code pode perguntar se você confia nos autores dos arquivos da pasta.

Na pasta criada por você durante a aula: siga a orientação do professor.

Em arquivo ou pasta de origem desconhecida: não marque confiança automaticamente. Peça orientação.
